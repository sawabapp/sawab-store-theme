# Sawab — Salla Twilight theme

An Arabic-first (RTL) Salla theme for home and utility stores, built on
Twilight. Home sections: hero, shop by category, product of the week with a
sale countdown, trusted brands, banner grid, stats, and blog articles.

```bash
pnpm install
pnpm run production   # build public/ (commit the production build only)
salla theme preview   # push first: Salla tags the local commit
```
